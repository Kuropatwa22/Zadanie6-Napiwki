# Zadanie 6 — Kalkulator napiwku

Zrobiłem aplikację do obliczania napiwku na podstawie przykładu z rozdziału 12.

Użytkownik wpisuje kwotę rachunku i wybiera procent napiwku za pomocą SeekBar.

Można też zaznaczyć zaokrąglanie wyniku w górę.

Po kliknięciu Policz aplikacja pokazuje całkowitą kwotę do zapłaty.

## Moja dodatkowa funkcja

Dodałem pole do wpisania liczby osób.

Program dzieli całkowitą kwotę rachunku z napiwkiem przez liczbę osób i pokazuje drugi wynik „Na osobę”.

Dodałem też sprawdzanie, czy liczba osób jest większa od zera.

## Czego użyłem?

- ConstraintLayout do ustawienia elementów.
- EditText do wpisywania kwoty i liczby osób.
- SeekBar do wybierania procentu.
- CheckBox do zaokrąglania.
- Group do pokazywania i ukrywania wyników.
- Button do liczenia i czyszczenia.
